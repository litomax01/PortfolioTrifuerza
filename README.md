# Leonardo Torres Quelal — Portfolio

Portafolio personal de Leonardo Torres Quelal, desarrollador de software Full Stack.
Hecho con Next.js, React, Three.js y Framer Motion. Bilingüe (español/inglés), con modo oscuro y claro.

**Sitio:** https://leonardo-torres-portfolio.vercel.app

## Ejecutar en local

```bash
npm install
npm run dev
```

## Formulario de contacto

El formulario envía los mensajes con [Formspree](https://formspree.io). Copia `.env.local.example` a `.env.local` y escribe el ID de tu formulario en `FORMSPREE_FORM_ID`.
